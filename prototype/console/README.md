# MaiWork 网页原型

界面原型，数据全是虚构示例，不连 MaiBot。风格照着 Muse：白底、粗大标题、3D 小图标、底部悬浮毛玻璃标签栏。

## 怎么打开

直接双击 `index.html`，用浏览器打开即可，不需要装任何东西。

- 手机：把浏览器窗口拉窄（或用浏览器的手机模拟），看到的是 Muse 式单栏 + 底部标签栏。
- 平板 / 窄窗口（760–1179 像素）：左边一列图标导航，详情从右边滑出。
- 桌面（1180 像素以上）：左边群和页面，中间内容，右边群脉搏和今天概况；点开任务或目标时详情显示在右边。

网址可以直接定位到某个群、某一页、某个任务，例如 `index.html#/k7Qm2x/tasks/T-0927`（`k7Qm2x` 是这个群的专属链接码）。

## 两种身份

- **群友**：打开本群专属链接（真实版里在群里发 `/mw 网页` 获取），只看本群、只读，可以给资讯和构想反馈；看不到其他群、关注成员、工具调用细节、设置和用量。不带链接码打开会看到一个说明页。
- **管理员**：点左下角「管理员」输入密码（原型里是 `maiwork`），看全部群，能批准、修改、看设置。截图时可以在网址后加 `?demo=admin` 直接进管理员身份，再加 `&sheet=settings` 或 `&sheet=models` 直接打开设置或模型设置。

## 页面

| 页 | 内容 |
|---|---|
| 资讯 | 按「周六傍晚 / 午后 / 早上」分批；每条写明为什么给这个群、现在的状态（开了话题 / 在候选里 / MaiBot 提过 / 过期）；可点有用 / 没用。没值得看的一批会写「跳过了」 |
| 构想 | 「我可以……」式的想法，带依据、第一步、要多久；可点「做这个」直接开工 |
| 目标 | 我在推进（带完成标准和进度）/ 帮大家记着（到点提醒） |
| 任务 | 等你批准（带原话）+ 全部任务（按状态筛选）；详情里有每一步工具调用 |
| 群 | 群脉搏（24 小时发言量、睡觉时段、冷场、开话题的位置）、开话题记录（可标对 / 错）、群画像（可锁定、删除）、关注成员（只有管理员看得到） |
| 设置（右上角，仅管理员） | 各群概况、**模型**（端点、密钥、主模型、子 agent 模型和备用；点「修改」可测试连接、从下拉里选）、今天用量、运行状态、规则、群链接 |

## 文件

- `index.html` / `style.css` / `app.js`：页面，纯 HTML + CSS + JS，没有任何依赖，以后可以直接由插件自带的网页服务提供。
- `data.js`：示例数据。
- `assets/icons/`：Microsoft Fluent Emoji 3D 图标（MIT 协议），缩到 128 像素。
- `assets/bot.jpg`：机器人头像。
- `screenshots/`：各尺寸截图。
