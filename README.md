# MaiWork

### 截图

![资讯](docs/images/news.png)

![手机](docs/images/mobile.png)

**MaiBot（MaiSaka）的常驻生产力Agent**

补全 MaiBot 的群聊生产力能力：为 MaiBot 提供一个并行的完整 Agent，理解一个群，主动找资讯、提构想、追目标，交付任何工作。

无感体验，与MaiBot使用同一套人设，它不抢 MaiBot 的话筒：不改回复频率，不拦 MaiBot 说话。想让群里知道的事，优先交给 MaiBot 在聊天里顺口提。

> MaiWork 是 MaiBot 的插件（插件 ID `chartyr.maiwork`）。

## 能做什么

- **资讯**：每天几个时段，按群里在聊的话题去网上找新消息和好文章，打分、去重，只留值得看的。
- **构想**：提一些「我可以帮你们做这个」的点子，写清楚包含哪几件事；挑中想要的，就可以开启对应的任务、追踪目标。
- **目标**：需要长期推进的事，MaiWork 会定期检查进度、自己往前做。它也会看群里最近在聊什么，偶尔主动提一个目标。
- **任务**：群友 @MaiBot 让它做事（查资料、做对比、写个小网页、出份 PDF……），MaiWork 接下来，派给干活的模型去做，做完自己先验收，不合格就打回重做。
- **开话题**：群里安静太久时，会从资讯和构想里挑合适的内容发起话题，后面的聊天交给 MaiBot。
- **交付**：通过群文件、临时网页（here.now）等方式交付结果，或者让 MaiBot 聊天时提一句。
- **MaiWork自身全掌控**：MaiWork保持对自身的完全掌控，可以在Web控制台中直接与MaiWork主模型对话，提出你的要求、偏好，MaiWork会搞定一切。

## 谁说了算

- **派活要批准**：群友派的活默认要管理员批准才开工。简单、低风险的任务会经过自动审查放行（可配置）；复杂长线任务会要求管理员批准。
- **两种管理员**：
  - 总管理员：看得到所有群，能改所有设置。
  - 群管理员：每个群可以单独设一个网页密码，只管自己这个群，也能在群里用 `/mw 批准`。
- **只碰你指定的群**：没写进配置的群，MaiWork 一条消息都不读。
- **个人画像不外传**：MaiWork 会给群里最活跃的群友记一点偏好，只有管理员能看，不会出现在群消息里，也不跨群。
- **不打扰**：主动发到群里的消息每天有上限，睡觉时段不开话题。

## 需要准备

1. 一个正在运行的 **MaiBot**（插件 SDK 2.x）。
2. 一个 **OpenAI 兼容的模型接口**：填一个「主模型」负责想和验收，一个「干活模型」负责执行。可以是同一个。
3. 一个**能联网搜索的 MCP**（比如 Tavily、You.com、EXA 的托管 MCP）：找资讯和做调研要用。
4. 可选：Jev（TypeSafe）密钥，让一些快速判断更快更省。

## 安装

1. 把 `plugin/CharTyr_MaiWork` 整个目录放进 MaiBot 的 `plugins/` 目录。
2. 在这个目录里把 `config.example.toml` 复制一份，改名为 `config.toml`，或在 MaiBot 的 WebUI 插件配置里直接修改 MaiWork 的配置，至少改两处：

   ```toml
   [plugin]
   enabled = true

   [[groups.serve]]
   group = "qq:你的群号"
   ```

3. MaiBot 会自动加载插件。管理员密码在 `<MaiBot>/data/maiwork/console_password.txt`（也可以在 `config.toml` 的 `[console] password` 自己设）。
4. 打开网页控制台（默认 `http://127.0.0.1:18650`），用管理员密码登录，**首次引导**会带你填完：模型、群、可选密钥、管理员和群管理员、头像。
5. 在「设置 → 扩展」里加一个搜索 MCP，点「用作联网搜索」。

想让群友外网访问，需要自己做反向代理，并把地址填到 `[console] public_url`。

> 所有设置都有默认值，默认什么都不做。网页上改的设置会直接写回 `config.toml`。

## 在群里怎么用

- **派活**：直接 @MaiBot 说要做什么，比如「@MaiBot 帮我对比一下这三款键盘」。需要批准的话，MaiWork 会告诉你在等管理员。
- **指令**：
  - `/mw` 看本群进行中的目标、任务和待批准的事
  - `/mw 网页` 拿本群网页链接
  - `/mw 批准 [ID]`、`/mw 拒绝 [ID]` 管理员用
  - `/mw 取消 [ID]` 发起人或管理员取消任务、目标、提醒

## 网页

- **资讯 / 构想 / 目标 / 任务**：每个群一套，群友用本群链接就能看，管理员能批准、反馈有没有用。
- **群**：MaiWork 眼里这个群的样子（群画像、关注成员），管理员可以改。
- **和 MaiWork 聊**：管理员直接问进度、让它调整做法。
- **设置**：模型、群、派活批准、推送节奏、扩展（MCP 和 skill）、干活用的机器等。

已适配手机、平板、PC端
