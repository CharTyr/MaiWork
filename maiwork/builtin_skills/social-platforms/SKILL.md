# 社交平台搜索

网页搜索找不到的，社交平台上可能有。什么时候去搜：

| 话题类型 | 推荐平台 | 为什么 |
|---------|---------|--------|
| 技术圈实时讨论、产品发布、开发者动态 | Twitter/X | 开发者多，反应快，英文内容多 |
| 深度讨论、用户反馈、冷门社区 | Reddit | 帖子长，讨论深，英文内容多 |
| 中文生活类、产品测评、教程 | 小红书 | 中文，生活化，图片多 |
| 中文视频教程、测评、开箱 | B站 | 视频多，中文 |
| 英文视频教程、演讲、评测 | YouTube | 视频多，英文 |

## 怎么用

用 `social_search` 工具：
- `query`：1–200 字的搜索词，通常 2–6 个词
- `platforms`：可选，平台 ID 为 `twitter`、`xiaohongshu`、`bilibili`、`youtube`、`reddit`。比如 `["twitter", "reddit"]`。
- `limit`：可选，默认 8 条

搜到的结果每条有 `platform` 字段，告诉你是哪个平台来的。

## 注意

- 社交平台的内容质量参差不齐，打分时要更严格。
- 要登录的平台如果没配 Cookie，会返回错误，别反复试。
- 视频平台（B站、YouTube）搜到的是标题和简介，要看内容得另外拿字幕。
- 连续两次搜不出新东西，就换下一种问法或下一个关注点（和网页搜索一样）。

搜索标题、简介和片段只作候选线索，不代表已打开正文。收进资讯前必须用 `fetch_page` 打开原文并取得支持摘要的依据；拿不到正文、字幕或可靠依据就放弃，不能把搜索片段当原文引用。搜索失败时按平台设置与登录态排查，不猜凭据，也不反复绕过搜索次数限制。
