# 资讯核实与摘要

这份只管一件事：**一条候选到底能不能站住、该怎么如实说出去**。
收什么不收、各项怎么打分、怎么找候选写在 `news-standard` 里，这份不重复它的数字与门槛；
两份都要用时先读 `news-standard`，再按这份做核实与摘要。

## 什么时候用

- 资讯流水线的核验环节：打开候选、判它是不是水文 / 低质转载 / 洗稿；
- 给资讯写卡片短摘要、写正文、写帖子；
- 做和资讯有关的任务，要核实一条消息真假、要给结论定强度；
- 解释「这条为什么算数 / 为什么不算数」。

## 一、把候选拆成可核对的事实

不要整条凭印象判。先把这条候选拆成一条条**能单独核对的事实**（谁、什么时候、做了什么、
数字是多少），再逐条核。核不动的事实单独列出来，不要让它混在结论里蒙过去。

- 每条事实都要能指到原文里的哪一句；
- 原文没说的、只是标题党暗示的，不算事实；
- 一条候选里核对不动的部分越多，它的可信度越低。

## 二、判假之前，先给最强反驳

要下「这条是假的 / 是水文 / 是洗稿」的结论之前，先说出**这条消息最强的成立理由**
（站在它的立场上把话说圆），再说明为什么还是站不住。

- 说不出最强反驳 → 你还没读懂它，先别下结论；
- 只能说出「感觉像假的」→ 这是怀疑，不是核实结果，要照实写成「没核实出来」。

## 三、按独立来源数算证据强度，不按链接数

**不同站点转载同一来源 = 一个来源**。通讯社通稿、一稿多发、同一家的不同栏目、
互相抄的中文科技站，都只算一个。

- 两个独立来源（各自独立采集或独立确认）→ 写「多源」；
- 只有一个 → 写「单源」，并且**不许**把它写成「已证实」；
- 拿不准是不是同源：看正文是不是同一段话、有没有共同的原始出处。

## 四、打开原文才算核过

- 只用搜索结果摘要、只看标题，**不算**核过；
- 打不开、要登录、要付费：如实写明「没打开」，不要拿摘要冒充正文；
- 页面跳转到别的地址：引用最终那个地址，别把中间地址当原文；
- 换过一次链接（原链接打不开、换了新链接）：新链接要重新核一遍，不能拿旧的结论顶上。

## 五、不确定就标出来

- 核不动的点写 `[不确定]`，并在交回的最后单列一份「未确认」清单；
- 摘要 / 正文里跳过不确定的值，不要用「约」「可能」「据称」把不确定糊成结论；
- 宁可少写一条，也不要为了把话说满而编一个数。

## 六、摘要规范

- **结论先行**：第一句就是这条消息最要紧的那件事，别先铺背景；
- **不改写原意**：不加原文没有的因果、评价、程度词；
- **保留限定条件**：时间、范围、口径、前提（「某地区」「测试版」「据厂商称」）都要带上；
- **数字照抄**：单位、口径、时间点照原文，不改算、不四舍五入、不换算成另一个口径；
- **不夸大**：单源不写成「已证实」，计划不写成「已经」，「考虑」不写成「决定」；
- 卡片短摘要与正文说同一件事，不要一个谨慎一个夸张。

## 七、引用规范

- 链接给**原文的最终地址**，不要给转载页、聚合页、搜索结果页；
- 一条事实一条链接，别把三个说法堆在一个链接上；
- 打不开的链接照实标明，不要拿它当依据；
- 引用里不出现内部说法（任务号、文件路径、子 agent 这类）。

## 八、翻过的车（核实环节的真事）

- **只看摘要就打分**：搜索结果摘要写得像新闻，打开原文才发现是三个月前的旧帖换个标题。
- **把两家转载当两个来源**：同一条通稿被两家站原样发出来，当成「多源」写进了结论。
- **把「可能」写成「已证实」**：原文写「据知情人士称可能」，摘要写成「已确认」。
- **链接指向聚合页**：引用的地址点开是一堆转载的列表页，不是原文。

## 九、交回

- 按 brief 里给的字段交回（`submit_result`），字段名和形状照 brief，不自己发明格式；
- 每条候选带上：判定结论、证据（原文哪一句）、来源链接、独立来源数（多源 / 单源）、
  不确定项；
- 核不动就写核不动，别用「大概是」「应该是」把交回填满。
