## 改动说明

- 正文改写为中文，并按 MaiWork 的目标机制重写：目标 = 一句标题 + 内容 + 3–5 条完成标准 +
  证据打勾（勾标准必须给 `task_id` 或群聊原话，由程序校验）。
- 删掉上游围绕 goal 工具的流程（调用工具查 / 建目标、把验证证据写进 objective 字符串、
  token 预算等）：MaiWork 没有那些工具，立目标与推进由主流程负责。
- 保留并本地化上游的质量门槛（具体结果 / 主要产物 / 怎么验证 / 在范围内 / 明确不在范围 /
  什么时候停下来问；可度量优先于装饰性精度；拒绝纯活动型目标）。
- 新增 MaiWork 特有的两段：**什么证据才算数**（连续 8 个字以上的群聊原话、或已验收通过的
  下级任务；计划 / 方案 / 网页 / 说明书不算）、**online / human 判断**（要群友自己动手的
  目标不能直接立，要改成一次性任务或只能不批）。
