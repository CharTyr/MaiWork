# 升级说明

[← 回到 README](../../README.md)

每一版改了什么、从旧版本升上来要注意什么。

## 最近几版的变化

当前版本 **0.9.3**：派活备忘优先分配预算，预算还有余量时太长就按句截断，措辞改成明确提醒 MaiBot「已由 MaiWork 接手，你不用答应，不要自己做」——实际回复效果仍需观察。任务按你的原话逐条验收，做到哪、卡在哪、要不要等你都能看见，卡住会停下而不是硬做。交付说明先给结论并 @ 你本人，文件发不出去会给能点开的网页或手机页。资讯卡片更短更干净：短摘要、「值得看」只放头条、配图统一画框不裁、末尾带本群网页二维码。长任务和长对话更稳：原始记录和压缩提要分开存，摘要失败保留原工作视图。随口一问就只回几句话，不会为一句闲聊开大工程。0.9.2 起任务被打回不再从零重来，同一个子 agent 带着前情接着改，第二次换更强的模型，第三次停下说明原因。0.9.1 起资讯来源更多样——按群里的真实反应自动订阅好来源的 RSS；搜索会参考各种搜法的成绩。构想先评估能不能做，做不到的不再提。0.8.0 起「往群里发多少 / 谁能批本群的活」每个群自己一份（在网页群页里管）。升级前请备份插件和数据目录，详见下面「升级要注意什么」。

## 升级要注意什么

老版本升上来基本不用手动改，插件启动时会自己迁移；只有想手写配置时才需要看新写法。

**升级前先备份插件和整个数据目录，覆盖插件时保留自己的 `config.toml`。** 0.8.0 会迁移数据库和每群记忆；如果回滚到旧版，需要同时恢复升级前的数据备份，不能只换回旧代码。

- **请求头覆盖（0.7.9 起）**：端点的高级设置新增可选 `headers`，默认空。升级时宿主会自动规范化配置版本（`0.4.6`），保留原有端点、密钥和群设置；没有设置覆盖时，请求行为不变。覆盖插件文件时务必保留自己的 `config.toml`。
- **群控归一（0.8.0 起）**：`[topics] enabled / per_day`、`[delivery] push_per_day / quiet_hours`、`[approval] required / admins / exempt_groups / exempt_users` 这九个全局键改成**每个服务群一份**（存数据库）。启动时会先按每个群把这份种好，**确认落库成功后**才把这九个键从 `config.toml` 删掉（改文件前先备份）；失败就一个都不删、下次启动再试，不会覆盖你已经在群页改过的每群设置。旧文件里的值此后只作**新加群**第一次的种子，网页和 `set_rules` 都不再能改它们。
- **「这个群怎么做」（0.8.0 起）**：原来的本群提醒、资讯偏好、每群工作记忆、逐条做事经验、口味小结合成**本群规矩 + 本群做法（skill）+ 群画像**三份，启动时把旧来源原文并进新表（旧文件备份后清空），「最近做过的」只留作去重材料。
- **模型（0.7.0 起）**：旧 `[models]` 那套四槽（`base_url` / `api_key` / `main` / `main_backup` / `worker` / `worker_backup`，加重试和限流）会在启动时**自动迁移**成「一个默认端点 + 模型库 + 各岗位的选择」；迁移成功后旧 `[models]` 才从 `config.toml` 里删掉，旧文件会先备份到 `<数据目录>/config-backups/`。新写法是 `[[endpoints]]` + `[[model_list]]`（见[配置说明](configuration.md#模型)）。
- **没迁完也不停摆**：模型库还是空的、旧四槽有值时，按旧规则继续干。
- **搜索**：老的 `[search]` 段不再读了，搜索改成在网页里绑定搜索服务（存数据库）；首次引导里直接勾预设就行。
- **管理员账号**：早期注释写的「纯数字」还能认，当 qq 号处理；正式写法是 `平台:账号`（如 `qq:123456789`）。公开示例里写的是占位号码，**请换成你自己的**。
- **0.9.3**：数据库会自动升到库号 37（给已有的资讯条目加一个短摘要字段；新建一张表存任务对话的原始记录和压缩提要，任务结束清空）。配置版本仍是 0.4.6，不用改配置。升级前请照旧备份插件和整个数据目录；**回滚请连同升级前的数据备份一起恢复**——旧版本不认这些新增内容，只换回旧代码不等于能继续用。
- **0.9.2**：数据库会自动升一级（库号 34 → 35，新加一张表存任务里的对话，任务结束就清空），配置版本仍是 0.4.6，不用改配置。回滚到 0.9.1 不用恢复数据库（旧版本不碰这张新表）。
- **0.9.0 / 0.9.1**：没有数据库结构变化（库号仍 34），配置版本仍是 0.4.6，不用改配置；自动订阅、来源地图用到的新数据都存在已有的键值表里。自动订阅默认就会运行，但不会往群里发消息，不想要的源在网页上删掉即可。
- **版本号**：`config.toml` 里的 `config_version` 是给程序比对默认值用的标记，一般不用手改。
