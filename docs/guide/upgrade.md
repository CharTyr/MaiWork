# 升级说明

[← 回到 README](../../README.md)

这篇文档告诉你两件事：**最近几版加了什么好用的新功能**，以及**从旧版本升上来要不要改配置、怎么备份回滚**。

---

## 一、升级前的一句话原则

> **正常升级直接覆盖插件文件、保留你自己的 `config.toml` 即可**——新增的配置项和数据库表都会在启动时自动补齐，不用手动改配置。
>
> 但凡事留一手：**升级前请顺手备份一下插件目录和 `<MaiBot>/data/maiwork/` 数据目录**。万一你想退回旧版本，必须把代码和当时的数据目录一起恢复。

## 二、最近几版的变化（0.11.0 ～ 0.15.1）

### 0.15.1 —— Windows 文件任务与组件兼容修复
> 配置版本 `0.5.4`、数据库库号 `49`（均无变化，**直接覆盖升级**）。

- **Windows 工作区文件操作补齐**：报告、网页等文件任务，以及从临时云端机器或专用 SSH 机器取回成品，使用适合 Windows 的安全读写方式；危险路径、符号链接、目录联接和硬链接仍会拦截。
- **画图组件识别更准确**：补齐 Windows Chromium 可执行文件位置，识别 macOS 和 Windows 自带的中文字体，并修正 Windows 组件子进程的系统路径。
- **社交平台私有目录兼容 Windows**：登录态、配置、缓存和临时文件均指向插件为本次调用准备的私有目录。
- **做法正文换行保持一致**：网页保存做法时按输入原样保留换行，手工放入的 Windows 文档也能正确分离说明与正文。
- Windows/macOS 的本机命令执行边界保持不变；需要运行命令的任务继续使用临时云端机器或专用 SSH 机器。Windows 上的 WEBP/GIF 成品按原文件交付，PNG/JPEG 照常按图片交付。

### 0.15.0 —— 看图做任务、闲时自己学新本事、设置与群管理页大整理
> 配置版本 `0.5.4`、数据库库号 `49`（均无变化，**直接覆盖升级**）。

- **真正能看图做任务了**：子 agent 新增看图与图片尺寸检查能力（兼容 OpenAI、Anthropic、Responses 多模态协议），执行任务遇到截图、海报、表格照片时会自动优先调用模型库里勾了「支持看图」的模型读取画面内容，不会再拿文本读取器硬读图片乱码。
- **做不到的活坦诚刹车，不再瞎试硬凑**：开工前如果发现任务必须看图但你还没配任何视觉模型、或任务超出当前环境能力，会直接用大白话说清缺什么并停下，不再白跑几轮凑一份假结果。
- **闲时自己探索成熟新做法（skill）**：群里之前卡住过的需求，MaiWork 会在闲时（每群每天最多 1 次）自己在隔离环境里查公开文档、挑成熟稳定的方案跑一次最小真实验证；验证真正跑通、通过安全检查后，自动存进本群做法库（标有「自动探索」标签），下次再遇到同类活直接照着做。
- **网页「设置」与「群页」全面重排，清爽好找**：
  - 全局设置从 11 个入口收拢为 **6 个清晰分组**（`概况` / `模型与专岗` / `工具与平台` / `群与来源` / `用量` / `系统`），页内用顶部分段标签秒切，旧书签地址全部自动跳转兼容；
  - 新建和编辑端点、模型、MCP、做法、专岗等长表单统一收进**右侧滑出抽屉**，不再把主列表顶得老长，后台刷新也不会冲掉你填了一半的内容；模型库顶部一眼看清「主模型 / 图片识别 / 图片生成」三项能力就绪状态；
  - 管理员看群页拆成 **「动态与画像 | 本群设置」** 两栏（普通群友打开依然只有干净动态），功能启用和主动发言开关改成**即点即存**的常驻拨杆。

### 0.14.0 —— 引用构想直接派活、群友提醒四修、本地成品永久副本与网页交互打磨
> 配置版本 `0.5.4`、数据库自动升到库号 `49`（**不用改配置**；若要回滚到 `0.13.0` 需连同备份的数据目录一起恢复）。

- **引用构想提一嘴直接派活**：群友在群里直接引用 MaiWork 发出的「构想提一嘴」消息并说「做吧 / 交给你 / 搞这个」，就会自动带上那条构想的完整方案立项派活（照常遵守本群审批设置）；构想详情和转任务交接包里也会保留触发灵感的群聊原话。
- **群友提醒四修**：定时提醒到点发群时改成真 `@` 发起人（不再只是纯文字名字）；一次性提醒响完自动结案归档；支持按天 / 周循环提醒；群友设提醒时的确认回执不再挤占群里的每日主动发言额度。
- **读群看懂图片和群空间**：读群聊时只读回填 MaiBot 已经识别好的图片和表情包文字描述，不再把群里的截图和表情当空白；同时支持只读浏览 QQ 群空间（相册、群公告、精华消息）帮群里找线索。
- **主动发言不撞车、备忘更干净**：顺口提备忘、冷场开话题、资讯卡片 / 构想提一嘴三条主动通道对同一素材 12 小时内互斥，不再前脚刚发卡片后脚又顺口重复提；给 MaiBot 的顺口提备忘按群定向投放，临时状态改走纯内存（不写库不锁库），过期旧备忘自动瘦身。
- **本地成品永久留档与一键重发**：任务产出的网页、报告、文档在本地保留永久副本，就算 24 小时临时公开外链过期，在网页点一下就能重新生成外链或重发群文件；分享页完整展示资讯图解，交接包附上核实过的参考链接。
- **网页与手机端交互动效打磨**：资讯页新增主题筛选与全文搜索，群页开话题记录默认折叠；手机上拉开底部详情抽屉可以直接手指按住往下滑关掉（滑一点松手自动弹回）；点「复制」按钮原地变成绿勾，右上角菜单从按钮角顺滑弹出、按 `Esc` 即可收起，点同意/拒绝后审批卡片平滑收拢，开启系统「减少动态效果」时保留柔和淡入淡出。

### 0.13.0 —— 给专岗配工具、在对话里查日志和试工具
> 配置版本 `0.5.4`、数据库库号 `48`（均无变化，**直接覆盖升级**）。

- **做法（skill）能给专岗带工具了**：在「设置 → 工具」新建或编辑做法时，可以勾选这份做法需要用哪些工具（内置工具或已连上的 MCP 工具）。在「设置 → 专岗」把这份做法挂给资讯、构想或目标专岗后，它们干活时就能直接调用这些工具（「专岗」页也会如实列出每个岗位当前能用的全部工具）。如果勾选了跑命令、写文件这类执行工具，保存和挂载前都会先弹确认框让你拍板。
- **「和 MaiWork 聊」能查调用、看漏斗、当场试工具**：在网页对话里可以直接让它查最近的工具调用记录（谁调的、传了什么、回了什么、耗时多久、报什么错）、看最近一批资讯的筛选漏斗（搜了几次、各来源带回多少、核实留下多少），还能让它当场试跑一次子 agent 的工具看通不通。
- **聊天体验优化**：后台管理员工具精简合并为 25 个，响应更准、更省 token；网页聊天框改为 `Enter` 换行、`Ctrl/Cmd + Enter` 发送，并且会保存模型的思考过程。

### 0.12.1 —— 专岗便条板、在对话里直接改设置
> 配置版本 `0.5.4`、数据库自动升到库号 `48`（**不用改配置**；若要回滚到 `0.12.0` 需连同备份的数据目录一起恢复）。

### 0.11.1 / 0.11.2 —— 密码加密升级、反向代理真实 IP、Windows 社交平台修复

### 0.11.0 —— 群内连续对话、开箱即用体验大升级

## 三、从很老的版本升上来要注意什么

如果你是从 `0.11.x`、`0.12.x`、`0.13.0` 或 `0.14.0` 升到 `0.15.0`，只管直接覆盖升级，下面这些都不用操心；只有从更老的版本跨大版本升上来，或者想回滚时，留意下面几条：

1. **回滚必须「代码 + 数据目录」一起回退**：凡是升过数据库库号的版本（比如 `0.11.0`、`0.11.1`、`0.12.0`、`0.12.1`、`0.14.0`），只把代码换回旧版、却留着新版的 `maiwork.db` 或已升级成 scrypt 的密码文件，旧版是认不出来的。回滚时请把升级前备份的整个 `<MaiBot>/data/maiwork/` 和 `config.toml` 一起拷回来。
2. **0.8.0 以前的全局审批与推送设置**：启动时会自动按群种进数据库，确认落库成功后才会把旧键从 `config.toml` 删掉（删前自动备份）。以后改审批名单和推送开关，请一律去网页对应群的页面里改。
3. **`run_as` 不能填 `root`（0.9.7 起）**：如果你以前在 `config.toml` 里把 `[environments] run_as` 手写成了 `root`，升级后出于安全隔离会拒绝运行，请改成 `maiwork`（系统会自动处理隔离账号）。
4. **群友链接默认公开到 here.now（0.11.0 起）**：如果你没配自己的 `public_url`、又不希望把群页面发到 24 小时有效的匿名公开页，升级后去网页「设置 → 系统 → 全部配置 → 网页」把「用 here.now 自动公开」关掉即可。
