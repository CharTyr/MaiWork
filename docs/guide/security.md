# 安全与公开范围

[← 回到 README](../../README.md)

在把 MaiWork 放进群里之前，花两分钟了解这三件事：**哪些东西外人能看到、它在 QQ 群空间里能动什么、隐私怎么兜底。**

---

## 一、发给群友的临时网页（here.now）是公开的

为了让群友不用配反向代理也能在手机和电脑上看报告、看本群资讯，MaiWork 默认使用 [here.now](https://here.now) 生成临时网页链接：

- **任务成品链接**：任务做完需要交网页或文件时，它只会把这一个任务的成品目录（`artifacts/<任务编号>/`）打包上传，绝不会把工作区里的其他文件带出去。
- **本群页面快照**：没填你自己的外网域名（`public_url`）时，群里发 `/mw 网页` 或推送资讯卡片带的链接，也是自动发到 here.now 的本群页面快照（包含群名、资讯、构想、任务进展；**不含**个人私下画像、QQ 号和管理员后台信息）。
- **24 小时有效，拿到链接的人都能打开**：因为是匿名公开页，**请不要让它处理包含个人隐私、内部账目或商业机密的内容**。
- **随时可以关**：如果你不想让任何内容发到 here.now，去网页「设置 → 全部设置 → 网页」把「用 here.now 自动公开」关掉即可（关掉后群里就只发文字，或者改用你自己的 `public_url`）。

## 二、群文件、群公告、群相册能动什么

当 MaiBot 用的 QQ 适配器支持群空间操作时，MaiWork 可以帮群里传文件、整目录、发公告、传相册（把 `group_space.enabled = false` 关掉就能一键全禁）。

为了防止它乱删群友的东西，代码里焊死了严格的边界：

| 群空间操作 | 硬性限制 |
|:-----|:-----|
| **删除 / 改名 / 移动群文件** | **只能动 MaiWork 自己传上去的文件**，群友传的文件一概不碰 |
| **新建群文件夹** | 会自动登记是自己建的 |
| **删除群文件夹** | 只能删自己建的文件夹；**只要里面还有任何一个别人传的文件，就绝不删除** |
| **发群公告** | 机器人自己在群里必须是群主或管理员；发公告前会先在群里说一声，且每群每天最多 1 条 |
| **上传到群相册** | 机器人必须是群主或管理员；只允许上传本群自己工作区里生成的图片 |

## 三、隐私与隔离底线

- **非服务群零接触**：没写进配置的群，MaiWork 连一条消息都不读、不记、不发。
- **个人画像绝不外传**：后台为活跃群友整理的个人画像，只给管理员在网页上看；给群友提点子时就算 @ 了本人，话里也绝不透露画像内容，更不会跨群共享。
- **密钥只进不出**：无论是配置文件里的密钥，还是在网页上填的模型密钥、搜索密钥、自定义请求头，保存后一律不回显；跟 MaiWork 对话查日志时，返回值也会自动把敏感凭据洗掉。
- **跑代码默认断内网**：子 agent 在本机隔离沙箱里跑代码时，默认禁止访问本机服务（`127.0.0.1`）、局域网和云服务器元数据地址，防止任务代码刺探你的服务器。
