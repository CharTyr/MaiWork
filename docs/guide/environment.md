# 运行环境与干活的机器

[← 回到 README](../../README.md)

这篇文档讲清楚三件事：装 MaiWork 需要什么、什么时候能直接在本机跑代码、怎么接云端临时机器或你自己的服务器。

---

## 需要什么

| 项目 | 要求 |
|:-----|:-----|
| **MaiBot** | 插件 SDK 2.x（在 **MaiBot 1.3.2** 上实测通过） |
| **Python 依赖** | `httpx`、`tomlkit`、`aiohttp` —— MaiBot 已经自带，**你不用额外装任何包** |
| **大模型** | 至少连一家模型服务商（支持 OpenAI / Anthropic / Responses 接口格式）；主模型负责统筹验收，各专岗没单独选模型时默认直接跟主模型用同一个 |
| **联网搜索** | 首次引导里直接勾选搜索服务预设（有免密钥直接能用的）；主搜索坏了会自动切备用 |
| **资讯卡片画图（可选）** | 用 Chromium 浏览器 + 中文字体把资讯拼成漂亮长图；如果系统里缺字体或浏览器，在网页「设置 → 工具 → 可选组件」里点一下就能自动下载到 MaiWork 自己的目录；还没装时会自动退回发文字列表，不耽误用 |
| **AI 生图（可选）** | 想让它画插画、封面图，在「设置 → 模型」里加一个用途选为「生图」的模型（OpenAI、火山方舟、硅基流动都行） |
| **办公文档（可选）** | 做 Word / Excel / PPT 所需的组件在「设置 → 工具 → 可选组件」里一键安装，不污染 MaiBot 的环境；若要把文档转成 PDF，服务器上需装有 LibreOffice |
| **加分项（全可选）** | ① 快速判断模型密钥（Jev / OpenRouter 等），让群里 @ 消息的识别更快更省；② 你自己的闲置 VPS 服务器；③ 一次性云端临时机器（Railway 默认免密钥开启，或配 Freestyle） |

---

## 本机能不能跑命令

有些活只需要「上网查资料 + 写报告网页」，任何系统都能直接做；但像「写段 Python 脚本算数据、抓网页、打包文件」这类需要**敲命令、跑代码**的活，必须放在隔离环境里才安全。

MaiWork 启动时会自动看你的系统环境，**不需要你手动建系统用户**：

| 你的 MaiBot 跑在哪 | 遇到要跑命令的活怎么办 |
|:-----|:-----|
| **Linux（带 systemd）且以 root 运行** | 直接在本机用 systemd 隔离沙箱跑：系统目录只读、禁止提权、限制内存（默认 512M）和时长、默认禁止访问本机与内网。系统里没有 `maiwork` 账号会自动分配临时隔离账号 |
| **Windows / macOS / Docker / 非 root Linux** | 为了保护你的电脑，**本机绝不直接跑命令**（查资料、写文件、出网页照常）。遇到要跑命令的活，自动交给下面的「一次性临时 VM」或你配的「专用机器」去做 |

> 你随时可以在网页「设置 → 运行状态」里看「本机干活」这一项目前是什么状态。出于安全底线，MaiWork **不提供**「关掉隔离直接裸跑命令」的开关。

## 专用机器（自己的 VPS / VM，可以配多台）

如果你有闲置的 Linux 云服务器或虚拟机，可以挂给 MaiWork 当专用干活机器。

只要你配了可用的机器（专用机器或下面的临时机器），**所有任务都会优先放到机器上跑**，只有机器全忙或连不上时才退回本机：先找你配的专用机器 → 都在忙就开一台一次性临时机器 → 再不行才回本机。

### 怎么把自己的服务器挂上去（5 步搞定）

前提：运行 MaiBot 的电脑或容器里装有 `ssh`、`ssh-keygen`、`scp` 命令（Windows 10/11 和 macOS 都自带；Docker 用户见 [Docker 部署](docker.md)）。

1. 打开 MaiWork 网页「设置 → 运行状态 → 自有机器」，点 **「复制公钥」**（这是 MaiWork 自动生成的一把专属 SSH 密钥）。
2. 登录你那台用来干活的 Linux 服务器，建议新建一个普通账号（不要用 root），把刚才复制的公钥贴进它的 `~/.ssh/authorized_keys` 里。
3. 回到 MaiWork 网页「设置 → 干活的机器」（或「全部设置 → 运行环境 → 专用 SSH 机器」），填上这台机器的名字、连接地址（格式 `用户名@IP:端口`）和一句备注（比如「4核8G，装了 Docker 和 LibreOffice」）。
4. 如果你有好几台不同特点的机器，可以在群规或说明里写清哪台干什么用，主模型派活时会照着挑。
5. 切回「运行状态」看一眼：显示绿灯就通了；连不上会直接用中文告诉你是公钥没加对、网络不通还是主机指纹变了。

> 每一台专用机器同一时间只接一件活，文件放在那台机器的 `~/maiwork/<任务编号>/` 下，做完自动把成品拷回 MaiWork 再交付。

## 一次性临时 VM（Railway，可额外加 Freestyle）

没有自己的闲置服务器也没关系。MaiWork 支持两家**用完即扔的一次性云端 Linux 机器**——需要跑代码时当场开一台，把活干完、成品拷回来，机器到点自动销毁。

两家可以在网页「设置 → 干活的机器」里同时打开、互当替补：

| 对比项 | Railway（默认开启） | Freestyle（可选） |
|:--:|:--|:--|
| **要不要注册填密钥** | **完全不用**，开箱即用 | 要去 [Freestyle 控制台](https://dash.freestyle.sh) 免费领一个 API key 填进设置 |
| **需要本机有 SSH 吗** | 需要本机能执行 `ssh` 命令 | **不需要 SSH**（全走 HTTPS 接口，特别适合精简 Docker 容器） |
| **机器配置** | 2 核 2G | 可选 2 核 4G（默认 `freestyle/ubuntu-sm`）或 4 核 8G（`freestyle/ubuntu`） |
| **用完怎么处理** | 等官方到点自动回收（约 60 分钟） | 任务一结束立刻主动销毁 |
| **每天默认上限** | 每天最多 2 台（官方限制同一网络出口每天最多 3 台） | 每天最多 5 台（免费档每月送约 100 机时） |

- 两家都开时，你可以在设置里选「优先用哪家」；优先的那家今天额度用完了或临时连不上，会自动无缝切到另一家。
- 机器一销毁上面的东西就全没了，所以子 agent 做完活必须把成品存进工作区带回来才算交付。

### Windows / macOS 上怎么用 Railway（不用 WSL2）

Railway 默认就是开着的，**不需要注册账号，也不需要装 WSL2、Docker 或虚拟机**，只要你的电脑能跑 `ssh` 命令就行。

- **macOS**：系统自带 `ssh`，什么都不用装，直接能用。
- **Windows 10 / 11**：系统自带 OpenSSH 客户端，按下面看一眼有没有启用：
  1. 打开 PowerShell，输入 `ssh -V` 回车。如果显示出一行版本号（比如 `OpenSSH_for_Windows_9.5`），说明已经齐了！
  2. 如果提示「找不到命令」，去 Windows「设置 → 系统 → 可选功能 → 添加功能」里搜 **「OpenSSH 客户端」** 装上；或者用**管理员身份**打开 PowerShell 跑这一行：
     ```powershell
     Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0
     ```
  3. 装完后**关掉并重新打开**运行 MaiBot 的窗口，去 MaiWork 网页「设置 → 运行状态」看「临时机器 · Railway」变绿即可。

> 如果偶尔遇到「当天额度用完」或校园网/公司网屏蔽了 22 端口连不上 Railway，去设置里把不需要 SSH 端口的 **Freestyle** 也配上，就有双保险了。
