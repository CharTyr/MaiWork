# 运行环境与干活的机器

[← 回到 README](../../README.md)

MaiWork 需要什么环境、在哪里跑命令，以及怎么给它配专用机器。

## 需要什么

| 项目 | 要求 |
|:-----|:-----|
| MaiBot | 插件 SDK 2.x；在 **MaiBot 1.3.2** 上实测 |
| Python 依赖 | httpx、tomlkit、aiohttp —— MaiBot 本身已带，**不用另装** |
| 模型 | 一个**模型服务端点**（OpenAI / Anthropic / Responses 三种接口格式都行）+ 一个**模型库**：「主模型」负责想和验收，各专岗负责动手；专岗没单独选就跟主模型一样 |
| 联网搜索 | 在首次引导里直接勾选搜索服务预设（免密钥的可以直接用）；主搜索坏了备用会自动接上 |
| 资讯卡片画图 | 用 MaiBot 环境里的 playwright + Chromium、Pillow 画卡片、处理配图；缺了就自动改发文字列表。没有中文字体 / 浏览器时，可在「设置 → 工具 → 可选组件」一键下载到 MaiWork 自己的目录（不需要 root）；浏览器缺系统库时仍需 root 运行 `playwright install-deps chromium` |
| 生图（可选） | 与资讯卡片画图相互独立：需要在「设置 → 模型」单独添加一个用途为「生图」的模型（OpenAI、火山方舟、硅基流动等），子 agent 才能画插画、封面 |
| 办公文档（可选） | python-docx、openpyxl、python-pptx 不随插件安装；在「设置 → 工具 → 可选组件」一键装到 MaiWork 自己的目录（默认 `/home/maiwork/pylibs`），只给子 agent 用，不动 MaiBot 的环境；转 PDF 要服务器上自己装 LibreOffice |
| 可选 | Jev 这类判断模型的密钥（TypeSafe 官方，或 OpenRouter、OpenCode、Command Code、Vercel、Upstage、Inception、Liquid AI、Cloudflare、OpenAI Decisions 任一家），让快速判断更快更省；自己的 VPS / VM（专用机器，可以配多台）；一次性临时 VM：[railway.new](https://railway.new)（默认，免密钥）或 [Freestyle](https://www.freestyle.sh)（要你自己的 API key，用完能主动销毁） |

## 本机能不能跑命令

**子 agent 在本机跑命令的方式，启动时自动判断，不用你建用户：**

| 你的机器 | MaiWork 怎么干活 |
|:-----|:-----|
| Linux + systemd，MaiBot 以 root 运行 | 放进 systemd 隔离单元跑命令：系统目录只读、禁止提权、限内存和时长。已有 `maiwork` 账号就用它；没有就**自动分配临时账号**，不用手动建 |
| macOS / Windows / 非 root / 没有 systemd（如 Docker） | 本机**不跑命令**（安全起见），查资料、写文件、做网页照常；要跑命令的活交给一次性临时 VM（Railway 或 Freestyle，设置里选）或者自行配置的其他机器（见下面「专用机器」），都没有就直说做不了 |

自动分配临时账号时，工作区在 `/var/lib/private/maiwork/workspaces`；不跑命令时，工作区在插件数据目录下的 `workspaces/`。启动后在网页设置页「运行状态」里的 **「本机干活」** 一项能看到当前是哪种方式。插件**不提供**「不隔离直接跑」的选项。

## 专用机器（自己的 VPS / VM，可以配多台）

只要有可用的机器（专用机器或一次性临时 VM），**所有任务都在机器上做**，查资料、写文件的任务也一样；本机只在机器都拿不到时使用（0.10.2 起）。顺序是：先用你配置的专用机器，都在忙或连不上时改用一次性临时 VM（见下面「一次性临时 VM」），再不行才回到本机；本机又不能跑命令的话，就直说做不了。

先确认 **运行 MaiBot 的环境**已经安装 OpenSSH 客户端，能执行 `ssh-keygen`、`ssh` 和 `scp`。Docker 用户要装在 MaiBot 容器内部，具体安装、验证和持久化方式见 [Docker 部署](docker.md)。目标机器则需要提供 SSH 登录服务（通常安装 `openssh-server`）。如果网页没有公钥，请先按「运行状态 → 自有机器」里的错误提示处理缺依赖或目录权限问题；首次检查完成前会显示正在准备公钥。

1. 打开网页设置页「运行状态 → 自有机器」，点「复制公钥」。这是 MaiWork 自己生成的一把 SSH key。
2. 把公钥加进那台机器的 `~/.ssh/authorized_keys`。建议给 MaiWork 单独开一个普通账号，不要用 root。
3. 在「设置 → 全部设置 → 运行环境 → 专用 SSH 机器」里一行一台，填三样：名字、地址（`user@1.2.3.4:22`）、备注（配置 / 用途）。
4. 可选：在「做事规矩」（AGENTS.md）里写清每台机器的情况和用途，比如「小黑：4 核 8G，装了 Docker，编译用它」「显卡机：只在跑模型时用」。主模型派活时会按这些说明挑机器。
5. 回到「运行状态」看每台连不连得上。连不上会写明原因：公钥没加 / 网络不通 / 主机指纹变了。

用法和限制：
- 每个任务在机器上用自己的目录 `~/maiwork/<任务ID>/`，做完把成品拷回本机再交付；
- 一台机器同时只接一个任务；
- 这台机器上的权限和隔离由你自己负责，所以请用专门给 MaiWork 的机器或账号。

## 一次性临时 VM（Railway，可额外加 Freestyle）

没配专用机器或专用机器都在忙时，MaiWork 会临时开一台一次性 Linux 机器做任务，用完即弃。有两家，**各自开关、可以同时开**（「设置 → 全部设置 → 运行环境」里的「Railway 临时机器」「Freestyle 临时机器」）：Railway 默认开着；Freestyle 是可选的额外一家，开了并填好密钥才会用。两家都开时，「优先用哪家临时机器」决定先用谁，先用的那家拿不到会自动换另一家。

| | Railway（默认） | Freestyle |
|:--|:--|:--|
| 要密钥吗 | 不要，匿名 | **要你自己的 API key**（[控制台](https://dash.freestyle.sh)里建，只在创建时显示一次） |
| 用完怎么办 | 官方没有销毁命令，等它自己过期（约 60 分钟） | 能主动销毁（做完就删掉） |
| 机器规格 | 2 核 2G | 由镜像决定：`freestyle/ubuntu-sm` = 2 核 4G（默认），`freestyle/ubuntu` = 4 核 8G（免费档上限） |
| 单条命令最长 | 10 分钟 | **5 分钟**（MaiWork 夹到 280 秒；更久的活要自己拆短或用后台进程 + 轮询） |
| 每台最长用多久 | 约 60 分钟（官方定） | 默认 90 分钟，可改 |
| 每天最多几台 | 默认 2（官方同一出口 IP 上限 3） | 默认 5；免费档每月约 100 机时（2 核 4G），用完后任务改回本机执行 |

- 同一时间两家合计只开 1 台；每家每天各有上限。网页「运行状态」里，启用中的每一家各有一条健康项（「临时机器 · Railway」「临时机器 · Freestyle」）。
- 你只需在设置里指定「优先用哪家」，MaiWork 会自动在两家之间切换。
- 拿不到机器（同时被占用、当天额度用完、平台拒绝、密钥不正确）会**自动换别的地方**：先换另一家临时机器（已启用的话），再专用机器，最后本机；任务详情里写明原因。
- 成品必须拷回本机工作区才算数，机器一到期上面的东西就没了。
- Freestyle 按**分配量**按秒计费（几核几 G 就算几核几 G），默认给 2 核 4G 是为了不让你无意中开大机器；密钥填写后不回显，网页上只显示「已设置」。
- 这两家都是按官方文档对接的，尚未在真实账号上长期验证；第一次使用请留意网页「运行状态」里的状态和当天用量。

### Windows / macOS 上怎么用 Railway（不用 WSL2）

Railway **不用注册、不用填密钥，默认就开着**。唯一的要求：运行 MaiBot 的电脑能用 `ssh`、`ssh-keygen`、`scp` 三个命令（MaiWork 靠它们连临时机器）。**不需要装 WSL2、Docker 或虚拟机。**

**Windows 10（1809 及以后）/ Windows 11** 自带 OpenSSH 客户端，只是有时没启用：

1. 打开 PowerShell，输入 `ssh -V`。显示版本号（如 `OpenSSH_for_Windows_9.5`）就说明已经有了，跳到第 3 步。
2. 提示「找不到命令」的话，二选一安装：
   - 「设置 → 系统 → 可选功能 → 添加功能」，搜「OpenSSH 客户端」，安装；
   - 或者用**管理员身份**打开 PowerShell，运行：
     ```powershell
     Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0
     ```
   装完**关掉再重新打开** MaiBot 的窗口（新装的命令要新窗口才认得）。
3. 重启 MaiBot，打开 MaiWork 网页「设置 → 运行状态」，看「临时机器 · Railway」那一项是否正常。不正常时那一项会写原因。

**macOS** 自带 ssh，不用装。

常见情况：
- 「当天额度用完 / 平台拒绝」：Railway 官方限制同一个网络出口每天最多 3 台、同时 1 台（MaiWork 默认每天自用 2 台），第二天恢复。想多一条退路，可以再开 [Freestyle](#一次性临时-vmrailway可额外加-freestyle)。
- 公司 / 校园网屏蔽了 22 端口时连不上，换个网络试试。
- 每台机器大约能用 60 分钟，长活请拆小。
