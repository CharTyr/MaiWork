# 功能详解

[← 回到 README](../../README.md)

装上 MaiWork 之后，它在群里和网页上具体是怎么干活的。

---

## 一、主动找资讯：不只搜标题，还会点开原文核实

每天固定几个时段（默认 08:30 / 14:00 / 19:00），MaiWork 会翻看群里最近聊了什么，定出几个搜索方向，并发去搜新消息。如果你在「设置 → 社交平台」里开了 B站、小红书、YouTube、Twitter 或 Reddit，或者给群绑了 RSS 源，这些渠道的内容也会一起进来参选。

为了不拿垃圾内容糊弄群友，它拿到搜索结果后还会做几道筛子：

- **点开原文核实**：派专门的核实岗位并行打开网页正文，把纯标题党、水文、洗稿转载、目录首页直接踢掉；只有真从正文里核实过的事实才算数。
- **不发重样、不钻牛角尖**：同一件事换个网站或标题不会发第二次；要是某件事有了真正的新进展，会作为「后续」接在老条目下面。同一个话题 3 天内最多发 3 条，逼着它往更宽的方向找。
- **只要新鲜的**：超过 7 天的旧闻直接丢掉。
- **数字多的时候自动配图解**：遇到没有配图但数据扎实的资讯，它会把文中的关键数字做成小图表直接嵌在网页里，并且逐个核对数字必须跟原文一致；对不上就宁可只放文字。
- **越用越懂你们群的口味**：群友在群里接话讨论、点开链接、或者你在网页上点「评价」挑了原因（太旧、没用、质量差），它都会记下来。表现好的网站会被自动订阅 RSS（先试用两周，没反应再自动退订），每周还会主动为你这个群发掘新的优质一手来源。

## 二、构想与长期目标：从群聊里发现「能帮上忙的事」

- **构想（点子）**：它不会凭空编造需求，而是看到群里真有人聊起某件麻烦事或心愿时，主动想出「我可以帮你们做这个」，并写清楚分哪几步做。管理员觉得靠谱，点一下就能直接转成任务或长期目标。
- **长期目标**：像「帮我们每周盯着某个开源项目的更新」「把群里的比赛报名和计分管起来」这种不是一次做完的事，可以立成目标（群友提的目标需管理员批准）。立好之后，MaiWork 会定期自己检查进度、自己派活往前推，阶段完成了或者盯到关键变化了，会在群里 @ 发起人汇报一声。

---

## 三、接活与交付：群里一句话派活，还能像跟同事说话一样连续改

群友在群里直接 @MaiBot 说要做什么（或者发 `/mw do 要做的事`），批准通过后就会开工。

### 1. 在群里连续对话（不用每次重新派活）
任务开工后，**派活的人直接在群里 @ 机器人**就能接着跟它聊这件活：
- **随时改主意、补要求**：「把第三部分换成表格」「再加一个价格对比」——正在跑的任务会立刻带着已做好的成果按新要求接着做，不用取消重来；
- **追问与回答**：「做到哪了？」它会用一两句大白话回你；如果它做到一半拿不准主意在群里问你，你直接 @ 它回答就能继续往下走；
- **随时暂停或收尾**：说一声「暂停」「继续」或「结束」就行。闲置 60 分钟没人理会自动收起，旁人 @ 机器人照常是跟 MaiBot 闲聊，互不干扰。

### 2. 主模型验收，不合格打回接着改
主模型自己不下场干苦力，而是先列好验收清单，派执行岗位去做，做完逐条核对产物：
- **第一次没过**：把具体哪条没过告诉刚才那个执行岗位，它记得自己刚查过什么、写过什么，直接接着改，不会从零重来；
- **第二次还没过**：把前面的过程浓缩成提要，自动换用你在「设置 → 专岗」里指定的强力模型来攻坚；
- **第三次还没过**：老老实实停下来告诉你卡在哪了，不硬编结果。
- 如果执行岗位发现你的要求本身自相矛盾或客观上做不到，它会先把能做的做完，再把异议和建议递上来请主模型和管理员拍板。

### 3. 能交付什么东西
- **好读的调研报告页**：查资料、做对比、写分析这类活，默认做成排版干净的报告网页（手机电脑、深色浅色模式都能舒服看），带表格、要点、引用来源和配图。
- **AI 生图**：在「设置 → 模型」里配一个用途选为「生图」的模型（OpenAI、火山方舟、硅基流动都支持），它就能画插画、封面和概念图，嵌进报告页或直接发到群里（涉及精确数字的统计图仍由代码绘制，不让生图模型乱画数字）。生图次数在「设置 → 用量与日志」里可查。
- **Word / Excel / PPT 与代码项目**：办公文档组件在「设置 → 工具 → 可选组件」里点一下就能装好；做好的文件优先直接传进 QQ 群文件，传不上去会自动给你一个 24 小时有效的下载网页。

## 四、岗位分工与「小便条」：几个专岗怎么配合

MaiWork 内部把活分成几个岗位：**主模型**（统筹和验收）、**资讯**、**构想**、**目标**、**通用任务**、**开话题**。

- **各岗位能用不同模型、挂不同做法（skill）**：插件自带了调研报告、资讯核实、通用任务、目标追踪、构想整理、办公文档 6 份现成做法。你可以在「设置 → 工具」里改做法或新建做法，还能勾选这份做法需要用哪些工具（比如让资讯或构想岗位也能调用某个搜索或 MCP 工具）。
- **岗位之间会互留便条**：同一个群里，比如资讯岗今天搜东西时撞见一条很适合群友某个长期目标的线索，它会留一张短便条贴在群内的便条板上（经主模型把关且不含隐私才贴出，14 天自动过期）。下一轮目标岗或构想岗干活时，抬头就能看到这张便条，不用各搜各的。

## 五、往群里发什么（克制、不抢话筒）

想让群友知道的事，MaiWork 优先写张小备忘递给 MaiBot，让 MaiBot 聊天时顺嘴提一句。只有下面几种情况 MaiWork 才会自己开口，而且**全部遵守免打扰时段**：

- **冷场开话题**：群里安静太久时，从最近的资讯或构想里挑一个话题抛出一句话，后面大家接话就归 MaiBot 聊了。
- **资讯卡片（每群单独开，默认关）**：每批资讯挑最值得看的 1~3 条拼成一张干净的长图发到群里，带本群网页二维码；如果缺画图组件发不出图，会自动退回发文字摘要，管理员也能在「设置 → 概况」里一键重发。
- **构想提一嘴（每群单独开，默认关）**：想到好点子时在群里提一两句；如果是专门帮某位群友想的，会 @ 本人，但绝不会把后台的个人画像说漏嘴。

> 上面这三项加在一起，共用**同一个每日主动发言上限**（默认每群每天最多 3 条），都在网页「群 → 主动发言」里按群开关。

## 六、网页工作台

打开网页控制台，按身份能看到不同的东西：

- **资讯 / 构想 / 在做的事**（群友也能看）：把本群的资讯、点子、正在跑的任务、长期目标和提醒整整齐齐摆在一起；管理员多了批准按钮和资讯评价按钮。
- **群**：看 MaiWork 总结的群画像和关注成员，管理本群的推送开关和审批名单。这里还有两样很实用的东西：
  - **本群规则**：你给这个群立的硬规矩（比如「不要推娱乐八卦」「代码一律用 Python」），MaiWork 绝对只读不改；
  - **本群做法**：它从每次验收和你的反馈里自己总结出来的做事经验，你可以直接改，也可以点「锁定」不让它再自己变动。
- **看板**（总管理员专属）：一页平铺所有岗位的实时工作流；点开任意一件活，能看到它调了哪些工具、传了什么参数、模型回了什么、思考过程是什么，以及岗位之间留了什么便条。
- **和 MaiWork 聊**（管理员专属）：像跟秘书说话一样管整个插件——问它某个任务为什么慢了、让它查最近的工具调用日志和资讯筛选漏斗、让它当场试跑一下某个工具看通不通，或者直接口头让它改模型、改专岗、配 MCP。凡是涉及发群消息、删数据或放宽权限的动作，都会先弹确认卡片等你点「同意」，密钥绝不进对话。
- **设置**：管理模型（端点与模型库）、各专岗配置、群链接与群管理员密码、工具（搜索 / MCP / 做法 / 可选组件）、社交平台、干活用的机器、外观主题，以及 token 用量与调用日志。
